# KShell

KShell 是面向 Android 的非官方 Kimi Code 远程控制客户端，基于 [ZShell](https://github.com/Amwidtf/zshell)，与 Moonshot AI 无隶属关系。

从 [Releases](https://github.com/Martin-ding0918/KShell-public/releases) 下载适用于 ARM64 手机的 APK。使用前，请在自己的 Kimi Code 桌面端开启远程控制，再扫描配对二维码或粘贴配对链接。

公开版可与旧自用版并存。需要迁移时，在旧版「设置 → 备份与恢复」导出加密配对备份，在公开版恢复并重新登录 Kimi 网页账号。确认新版本可用后再考虑卸载旧版。
